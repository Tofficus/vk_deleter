# vk_deleter
Script for deleting posts from your vk page


СКРИПТ ДЛЯ УДАЛЕНИЯ ПОСТОВ ВК 2025.10.18
Версия: 8.1

ИНСТРУКЦИЯ:
1. Откройте свою страницу ВКонтакте (https://vk.com/)
2. Нажмите F12, откройте вкладку "Console" (Консоль).
3. Вставьте этот ВЕСЬ код и нажмите Enter.
4. Следите за сообщениями в консоли.
